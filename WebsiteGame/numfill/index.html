How to play NumFill

Some boxes in the grid are empty. Tap an empty box and choose a number from 1 to 9. Every row and every column has a clue on its end. The clue shows sum ÷ number = answer. Multiply the two numbers to find the total that the line must add up to. For example, sum ÷ 3 = 5 means the numbers in that line must add up to 15.

Some clues only show = total. Then the line must add up to exactly that number.

Lives, hints and score

You start with 3 lives. When the grid is full but a line is wrong, you lose a life. You have 3 hints per game. A hint fills one correct number. Faster solves and no mistakes give bonus points. Every 3 levels you can win back a life.

Tips

Start with lines that have only one empty box. Subtract the numbers you can see from the total to find the missing one. Then use the new number to solve the crossing line. Green clues mean the line is correct.
